# Trabajo Final de Paradigmas de Programación 5

En este repositorio se encuentran las entregas y avances del proyecto final de la cursada de Paradigmas de Programación 5.

---
## Definición del Proyecto

El proyecto es un sistema de gestión para un Centro Regional de Coordinación de Emergencias, que permite coordinar operaciones, administrar los recursos disponibles, registrar las
actuaciones realizadas y conservar información sobre la evolución de las emergencias que atiende dicho centro.
